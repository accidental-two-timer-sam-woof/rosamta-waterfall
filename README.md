# rosamta

> 開發版已可初始化來源、查詢設定、預覽變更並套用 dotfile。

`rosamta` 是一個跨平台、跨裝置的 dotfile 管理工具。除了同步與部署設定檔之外，它的核心想法是：**把多個程式共用的設定抽成「模組」，用一份設定同時產生多個 dotfile。**

例如配色、字型、shell 環境變數這類設定，往往分散在終端機、編輯器、tmux 等多個程式的設定檔中。透過模組，使用者只需維護一份設定，就能一次套用到所有相關程式。

## 開始使用

從儲存庫根目錄執行 `cargo run --locked -- --help` 查看指令。建置方式、目前可操作的範圍和 exit code 見[操作手冊](docs/07-user-manual/user-manual.md)。模組分工與實作進度見[詳細設計 §3](docs/05-detailed-design/detailed-design.md#3-套件結構)。

## 核心概念

- **模組（Module）**：描述某一類「多個程式都會用到」的設定，例如配色、字型、shell 環境。使用者只需要編輯模組檔。
- **範本（Template）**：把模組的值轉換成特定程式的設定格式。範本可以由使用者自訂，也可以覆寫內建範本。
- **主機設定（Profile）**：依照作業系統、主機名稱或自訂標籤，決定要啟用哪些模組與範本，以及輸出的位置。

```
theme ──┬──> 終端機設定
        ├──> 編輯器配色
        └──> tmux 配色
```

## 內建模組

內建模組可搭配 Ghostty、Alacritty、POSIX shell 與 PowerShell 的範本：

| 模組 | 用途 |
| --- | --- |
| `theme` | 配色、透明度等外觀設定 |
| `font` | 字型、字級 |
| `shellrc` | 環境變數、alias、PATH |
| `terminal` | 終端機共通行為，如游標、捲動、快捷鍵 |

使用者也可以撰寫自己的模組與範本，管理內建模組未涵蓋的程式。
